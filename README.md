
# Organizador de Precos de Supermercado

## Sobre o projeto

Este projeto foi desenvolvido em linguagem C para demonstrar
a utilizacao de dois algoritmos de ordenacao: Bubble Sort
e Quick Sort.

A aplicacao organiza os precos de dez produtos ficticios
de um supermercado em ordem crescente.

## Situacao-problema

No cotidiano, comparar os precos de produtos ajuda o consumidor
a identificar os itens mais baratos e a organizar suas compras.

Quando existem varios precos, ordena-los facilita a visualizacao
e a comparacao dos valores.

## Objetivo

Implementar os algoritmos Bubble Sort e Quick Sort, utilizando
os mesmos dez precos, e apresentar os dados antes e depois
da ordenacao.

## Tecnologias utilizadas

- Linguagem C
- Compilador GCC
- Git e GitHub para versionamento e hospedagem do codigo

## Algoritmos utilizados

### Bubble Sort

O Bubble Sort percorre o vetor comparando elementos vizinhos.
Quando dois elementos estao fora de ordem, suas posicoes sao
trocadas.

Esse processo se repete ate que os valores estejam ordenados.

Sua complexidade media e de O(n²).

### Quick Sort

O Quick Sort escolhe um elemento chamado pivo e divide o vetor
em duas partes: uma com valores menores ou iguais ao pivo e
outra com valores maiores.

Em seguida, aplica o mesmo procedimento recursivamente
nas duas partes.

Sua complexidade media e de O(n log n), embora no pior caso
possa chegar a O(n²).

## Resultados esperados

O programa apresenta:

1. Os precos na ordem original.
2. Os precos ordenados pelo Bubble Sort.
3. Os precos ordenados pelo Quick Sort.

Os dois algoritmos devem apresentar os mesmos valores
em ordem crescente.

## Conclusao

O projeto demonstra a aplicacao pratica de algoritmos de
ordenacao em uma situacao cotidiana.

A implementacao permite observar o funcionamento do Bubble
Sort e do Quick Sort e comparar os resultados obtidos.
